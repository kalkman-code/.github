Kalkman Code is where Toby Kalkman ships his software: released apps, commissioned work and the private infrastructure behind it. What I choose to release is free.

## Released here

| Project | What it does |
| --- | --- |
| [Beamer](https://github.com/kalkman-code/beamer) | One keyboard and mouse for a Mac and a Windows PC on the same network, in either direction. The clipboard comes with it. Encrypted, and nothing goes through a server. GPL-3.0. |

## Released elsewhere

- [HorseDex](https://horsedex.co.uk): a health journal for a horse, free on the App Store for iPhone, iPad and Mac.
- [Tabby](https://chromewebstore.google.com/detail/tabby/lldnfmijjembgbikleiicjbokimlfjhn): moves a window's tabs to and from a plain text file, free on the Chrome Web Store.
