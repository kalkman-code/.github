Kalkman Code is where Toby Kalkman ships his software: released apps, commissioned work and the private infrastructure behind it. What I choose to release is free.

## Released here

| Project | What it does |
| --- | --- |
| [Beamer](https://github.com/kalkman-code/beamer) | One keyboard and mouse for Macs, Windows PCs and Linux machines on the same network, with the clipboard, over an encrypted direct link with no server in the middle. Linux is an experimental Flatpak. GPL-3.0. |
| [Dimmer](https://github.com/kalkman-code/dimmer) | A macOS menu bar app that dims a MacBook's keyboard backlight and screen as you close the lid, from the hinge sensor. GPL-3.0. |

## Released elsewhere

- [HorseDex](https://horsedex.co.uk): a health journal for a horse, free on the App Store for iPhone, iPad and Mac. Closed source.
- [Tabby](https://chromewebstore.google.com/detail/tabby/lldnfmijjembgbikleiicjbokimlfjhn): moves a window's tabs to and from a plain text file, free on the Chrome Web Store. GPL-3.0.

Launchdeck, Bakeoff, Slotter and Claude Sweeper are coming soon and are not public yet. Everything is at [kalkmancode.co.uk](https://kalkmancode.co.uk), and changes are posted at [kalkmancode.co.uk/updates](https://kalkmancode.co.uk/updates).
